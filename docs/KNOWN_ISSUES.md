# 已知问题与验证缺口

状态日期：2026-10-09 UTC。0.1.2 完成下述结构/数据质量修复，本轮未新增模型调用、安装或 WPS 配置/许可操作。

## 1. 全部原始文件实读和完整端到端仍未通过

此前匿名完整单阀调用退出码为0，但模型承认未直接打开原始 `diagnostic.pdf` 与 `diagnostic.devdata`。日志记录3次原件读取工具失败；白名单和外层本地哈希探针通过不能证明模型内部工具可读。缺少完整工具清单、底层错误及执行上下文证据，根因未证实。

0.1.2 要求逐原件路径、哈希、读取状态、方式和轨迹引用。未读/失败、漏项、重复和不匹配均不能进入待审或冻结，拒绝结果保留本地审计记录。审核、冻结、冻结包加载和继承重复校验；旧版已冻结包缺少声明时仅标为 `legacy_unrecorded`，不改写旧包。

该门禁验证自报声明的结构和绑定，`reported_complete` 不是独立读取证明或工程验收。真实工具读取失败尚未被修复或重新实测；后续模型调用必须另行获准。不能以图片、转录、参数快照或通过单元测试替代原件实读。

## 2. 报告执行机构型号回填已移除；另有既有特例待业务核实

`business_report.specification_supplement_rows` 不再从阀型号两位前缀补执行机构型号。88-21124、99-ABC12 及原有51前缀用例均保留型号缺失；明确执行机构型号仍保留。已检查纯数据和诊断两种实际 DOCX 渲染路径。

提取层 `_derive_actuator_display_from_spec` 仍保留阀型号后缀 `-21129` 的既有显示型号特例及其原测试。本轮限定修复报告层通用前缀回填，没有扩大修改这个独立业务规则；其现场适用性和独立来源依据没有在本轮重新核实，不能从本次测试推定已验证。

## 3. 规格标签已扩展，OCR 与未知模板覆盖仍有限

0.1.2 支持已验证标签的可选中英文冒号、空白和换行，以及 `Model Number`、`Valve Size`、`Pressure Class` 等别名；显式处理受测单位，保留原数值和单位口径，不进行无依据的换算。支持的数字型号21000为带标签的字面值，不是型号映射。

已匹配规格页上的非空值无法安全归一化时，保留原文本、源路径/哈希/页码，以 `source_present_parser_missing` 进入带图复核；空栏或无标签保持真实缺失，不借用其他阀页。提取器版本从6升至7，旧提取快照必须按既有批准和版本合同重新处理，不能把旧缓存视作新解析结果。

未知型号、单位、复杂表格和其他未覆盖版式仍可能需要人工复核。此前单独使用的 Tesseract 英文兼容适配器并非原作者服务，不包含在仓库；其 `tables=[]`、`confidence=null`、`degraded=true`。中文、复杂表格、模糊或倾斜现场扫描仍未验证。本轮仅本地合成/保存文本回归，未重新启动外部 OCR 服务。

## 4. WPS 正式交付未验证

WPS 应用未安装验收，适用许可证未核实，正式 PDF 与分页视觉验收均未完成。`pywpsrpc` 存在不等于 WPS 可用。LibreOffice 只用于内部检查，不能冒充正式交付。
