# 历史曲线看图分派说明

本文件只用于识别旧运行，不再是可执行合同。正式诊断统一使用
[单阀一体化模型合同](integrated-valve-diagnosis.md)：每台阀门由主 Agent 直接串行执行，不使用子代理，
完成一次 `gpt-6-sol`、`reasoning_effort=high` 的 `codex exec`（当前提交器合同），在同一调用中读取完整证据、全部曲线和技术页，并同时输出逐图
观察、逐图工程判断和整阀综合诊断。

不得恢复独立单张读图阶段，不得使用 Luna，也不得把不同调用产生的观察与
整阀结论重新拼接。旧运行如需修订，应创建新诊断版本并按一体化合同重做整台阀门。
